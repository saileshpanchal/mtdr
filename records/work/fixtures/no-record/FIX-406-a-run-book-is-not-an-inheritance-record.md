# FIX-406 — a run book is not an inheritance record

> **Fictional worked fixture.** Hollin Vale Building Society is invented.

**Proves:** procedural material yields **no candidate**, confidently. The OIR replaces no run book.

## Source

**A — Run book RB-EXC-v6, "Repairing an account-name mismatch"**

> 1. Open the exception in the repair queue. 2. Search the member record. 3. Compare the account name.
> 4. If it differs, correct it and press Resubmit. 5. Close the exception with code AN-01.

Nothing else: no purpose, no commitment, no threshold, no authority, no obligation.

## Expected

- **Zero candidate OIRs.** The output states that the material is procedure — how a task is done —
  and that no inherited state is evidenced.
- The run book may be noted as a source a future OIR's **You should** could reference.

## Must not

- Draft an OIR titled after the run book or the repair queue.
- Promote the five steps into jobs.
- Infer inherited context — a threshold, an assumption, a risk — that the run book does not state.
- Return nothing at all: the output must say *why* there is no candidate.
