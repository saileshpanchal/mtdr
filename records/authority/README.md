# Package — Authority

**Language:** authority · **Primary record (proposed):** `OAR` — Operational Authority Record
**Status:** `candidate` — the [record admission test](../../specification/record-admission-test.md)
has **not** been passed.

## Semantic scope (reserved, not admitted)

Operational authority: delegation, scope, conditions, limits and provenance — the governed answer to
*who is entitled to act, on what, within which bounds, granted by whom*. Human and AI participants
exercising bounded organisational authority under traceable delegation.

Bounded against the existing languages: a **decision** (TDR) may *establish* an authority, and this
language would record the standing delegation that results — not the judgement that created it. A
**value commitment** (VR) carries `authority` as a traceable reference; this language would be what
such references resolve to.

## What this package contains

This README. Nothing else — **candidate packages contain metadata and scope only**
([TDR-0021](../../decisions/TDR-0021-record-package-architecture.md)). No specification, schema,
template, examples, validation rules or skills exist until admission succeeds, and none may be added
here before it. A directory confers no maturity.

Admission, when proposed, arrives as a TDR carrying the four classification answers with evidence, a
failing query no existing language can answer, and a bounded semantic scope.
