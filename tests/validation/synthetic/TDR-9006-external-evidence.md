# TDR-9006 — synthetic subject

Identical to TDR-9005 except that it cites ratification evidence, in a system the declared evaluation
context does not reach. (The citation uses the `x-` extension namespace TDR-0015 opened, because the
evidence binding itself is not a governed frontmatter field.)

An assessor can establish that a citation exists. It cannot establish that the evidence exists, says
what the record claims, or satisfies the prerequisites — so eligibility is unknown rather than failed.
The citation is a claim *about* evidence, and eligibility resting on the subject's own assertion would
be circular.
