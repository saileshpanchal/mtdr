# TDR-9005 — synthetic subject

Nothing is wrong with it. It parses, it is coherent, its lineage resolves, and it occupies the
`proposed` state legitimately.

What it does not have is evidence of an authorised human act, which TDR-0027 requires before the
transition to `accepted`. That absence is permitted in the state it is in and disqualifying for the
state it requests — the distinction TDR-0033 exists to make reportable.
